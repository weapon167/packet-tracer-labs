# Packet Tracer Labs

A collection of Cisco Packet Tracer network designs, built as hands-on practice alongside CompTIA Network+ (N10-009) and Cisco CCNA-style study. Each lab applies subnetting/VLSM design to a real topology, with full device configuration.

## Labs

| # | Lab | Topology | Status |
|---|---|---|---|
| 01 | [Office VLAN — Router-on-a-Stick](./01-office-vlan-router-on-a-stick) | 1 router, 1 switch, 4 department VLANs (Sales, HR, IT, Finance) routed through sub-interfaces | In progress |

## What Each Lab Folder Contains

- A `.pkt` file — the Packet Tracer project itself
- A `README.md` — topology summary, addressing plan, and build status for that specific lab
